# Propovo hosted MCP guide

Guide to [Propovo](https://propovo.com/)'s commercial hosted MCP service. This repository contains documentation, not application source, an open-source server or SDK.

## Connect

Endpoint:

```text
https://api.propovo.com/mcp
```

Follow the [current setup guide](https://propovo.com/mcp) for Claude and ChatGPT. Connect with OAuth, sign in, choose a workspace and review permissions. Availability depends on your AI app and workspace policy.

## Access and review

- Approve only necessary workspace permissions; Propovo roles and plans still apply.
- Review discovered tools. Review drafts in Propovo before sharing.
- Revoke connections in Propovo's Integrations settings. Saved drafts remain available.

## Four practical prompts

Replace brackets with your own intended workspace context.

1. **Find my latest proposal in Propovo.**
2. **Find the Propovo proposal for [client/project].**
3. **Save these client notes as a private proposal draft in Propovo: [notes].**
4. **Prepare a proposal draft from this scope and pricing for review: [details].**

## Troubleshooting

| Situation | Check |
| --- | --- |
| Connection unavailable | Host availability and workspace policy. |
| Unexpected documents | Selected workspace and approved permissions. |
| Expired/revoked connection | Reconnect; the guide specifies 90 days. |
| Draft prepared | Review in Propovo before sharing. |
